# The Java surface the Doft VPN app already binds to, extracted with `javap` from the
# 54 MB libv2ray.aar that was committed to doftinc/flutter_v2ray_client (ref ffc5f2e)
# without provenance — no source, no build, no pin.
#
# Every line here is asserted to be PRESENT in the AAR this repo builds. That is the whole
# point of the file: the previous AAR is a binary nobody can rebuild, so the only way to
# replace it safely is to prove the replacement still answers everything the app calls.
# Extra symbols are fine (we add some); a MISSING one means the plugin will not compile,
# or worse, compiles against a different overload.
#
# Format: one `class::signature-fragment` per line, matched as a plain substring against
# the javap -classpath output for that class. Comments and blank lines ignored.
